# ContactEase Solutions

**ContactEase Solutions** simplifies the management of phone contacts by offering an intuitive, command-line interface to easily add, modify, delete, and search contacts.

The goal is to provide users with an easy-to-use solution that allows them to manage their contacts directly from the terminal, using **Object-Oriented Programming (OOP)** in **Python**.

### Features:
- **Manage contacts**: Add, edit, delete, and search for contacts.
- **Save and load contacts**: Supports saving contacts in a file (CSV and JSON) for easy access.
- **Command-line interface**: Simple and interactive UI for quick contact management.

### Requirements:
- **OOP**: Structured, scalable code using object-oriented principles.
- **Efficient data structure**: Optimized for quick access and management of contacts.
- **Core functions**: Adding, modifying, deleting, and searching contacts.

### How It Works:
1. Add new contacts with name, phone
2. View, modify, or delete contacts.
3. Search by name to find contacts quickly.

### Future Enhancements:
- **Additional file formats**
- **Graphical Interface (GUI)**: Future updates may include a GUI for better user experience.

**ContactEase Solutions** is the ideal tool for managing your phone contacts with simplicity and efficiency.
